# Подготовка ПК к работе

## Доступ в GIT по SSH

1. Открыть консоль

2. Ввести `ssh-keygen -t rsa -C "comment"`.

   Комментарий нужен для идентификации созданного ключа.

   Если придерживаться правила "одна машина — один ключ", то стоит вписать имя компьютера.

3. Оставляем всё пустым:

    - Enter file in which to save the key:
    - Enter passphrase (empty for no passphrase):
    - Enter same passphrase again:

4. По завершении появится путь, где был создан ключ и его отпечаток.

   Стандартный путь для Windows — `%userprofile%\.ssh`

5. Открываем файл `id_rsa.pub`, копируем содержимое

6. Заходим в GitLab/GitHub

7. Добавляем ключ. Профиль > Настройки > SSH Keys > New SSH Key

   Писать название необязательно, если был прописан коммент к ключу — он подтянется автоматически.
